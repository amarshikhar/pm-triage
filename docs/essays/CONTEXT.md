# Decision context, in essay form

There is deliberately almost nothing in this file. The canonical current
decision log is the `CONTEXT.md` at the root of the repository, one level above
the documentation folder, and this file exists only to point at it.

The indirection is the point. There were previously two separate context files
saying overlapping things, and they had begun to drift apart — naming different
models, different databases, different test counts, and different evaluation
claims. Collapsing one of them into a pointer means there is now a single place
where those facts live, and no second copy that can quietly go stale.
