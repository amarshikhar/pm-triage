PM Triage — five-slide presentation
01 / 05What it is

Telemetry goes in. A person signs the work order.

PM Triage turns condition-monitoring telemetry into an evidence-backed maintenance case. Deterministic rules detect the abnormal reading. Physics rules plus one narrow trained model name the fault — or abstain. A language model retrieves precedent, explains the evidence and drafts the work order. A named planner must approve before an idempotent adapter writes anything to the maintenance system of record. No AI step can move a machine, set a priority, or authorize work. That boundary is structural, not a policy note.

02 / 05Architecture — the flow

One abnormal reading, left to right

Everything left of the dashed line is a proposal. A work order is created in exactly one place, after exactly one state transition, by a request carrying a bearer token and a reviewer name — no autonomous path from telemetry to action.

Who decides what

DecisionOwner
Is this reading abnormal?Deterministic code — fixed limits, sustained robust median/MAD
What kind of fault is it?Physics rules first; the trained model only for the overlapping pair
Is the evidence strong enough to answer?Calibration on precedent and signature; below 0.45 it abstains
How is it explained, what is proposed?The language model — mock or live, identical tool protocol
How urgent is it?A published formula. The agent may move it one notch, never below P1
Does any work actually happen?A named human, on every case, including high-confidence ones
Where does approved work land?The CMMS, over HTTP, idempotently

Why the boundaries sit there

  • Detection is deterministic because it must be cheap, continuous and readable by a technician. The same reading always gives the same result.
  • The trained model is deliberately narrow. A novelty score and an exact sensor-roster check make it abstain outside its job rather than answer confidently in a domain it never saw.
  • The language model never decides, so a fluent wrong answer costs an explanation, not a maintenance action. And confidence is grounded, not self-reported — a model's own certainty tracks fluency, not correctness.
Priority is arithmetic, not prose.
score = criticality + 2×severity + min(recurrence,3) + 4 if safety
P1 if safety or ≥13 · P2 ≥10 · P3 ≥7 · else P4

05 / 05How this is judged

Six categories, and what each one is allowed to claim

Category Weight Evidence in this artifact Do not overclaim
Solution architecture & workflow design
30%
 One owner per decision; the full telemetry-to-CMMS state machine; a fallback at every failure point. A focused working slice, not a complete plant platform.
Software engineering & SDLC
25%
 Typed FastAPI and Next.js contracts, 105 backend tests, a production build, live deployment, retention. No formal SRE maturity or exhaustive browser E2E testing.
Systems integration & enterprise architecture
20%
 REST APIs, Supabase Postgres, an HTTP anti-corruption adapter, schema translation, retries, idempotency. The mock CMMS is mounted in the same deployment and shares the database.
Domain-embedded business architecture
15%
 Criticality, engineering limits, signal features, precedent, P1–P4 priority, downtime exposure, a human planner. Thresholds, history and economics are demo inputs, not validated policy.
Agentic AI / LLM engineering
7%
 A bounded tool loop over three read-only tools, structured output, mock/live parity, an eval suite, provider fallback. The LLM owns no detection, no authorization, and cannot overrule a classifier verdict.
Governance, observability & control
3%
 OOD rejection, abstention, mandatory approval, an append-only audit trail, call and dollar caps. Demo authentication is a signed crew-password session, not SSO or RBAC.

Limitations — volunteer these before you are challenged

  • Eight laboratory episodes are development evidence, not customer-site validation — and the frozen restriction test is only three physical recordings.
  • The trained layer solves one pair. Everything else is a rule, or an abstention. CWRU episodes are constructed transitions, with redistribution terms still to confirm.
  • Process memory is not shared state. The replay cursor and triage queue live in one process; multi-replica needs a durable broker and a crash-recovery scanner.
  • Schema setup uses create_all, not Alembic migrations. The frontend polls; it does not consume an event stream.

The sentence to close on

Rules detect. Rules plus narrow ML classify. The OOD gate can abstain. The LLM explains and retrieves. A named human authorizes. An idempotent adapter integrates the approved decision. That division is the production design — not a limitation of the prototype.
Next: customer-owned natural fault-onset recordings, especially discharge and cavitation; an external validation set that tests the thresholds without changing them; then monitor acceptance, selective accuracy and drift in production.
